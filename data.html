Data tools

Import from Excel

Load leave from an Excel or CSV file, for example the HR "Staff Leave tracker". The file needs columns for ID, Name, Department, From and To. Mixed date formats are fine.

Download a backup

Saves every leave entry as a CSV file that opens in Excel. Photos of signed forms aren't included.

Publish the list for everyone

Downloads a data.js file. Upload it to the GitHub repo, replacing the old one, and every device then starts from this list.

Start over

Throws away every change made on this device and goes back to the published list. Photos taken on this device are deleted too.
